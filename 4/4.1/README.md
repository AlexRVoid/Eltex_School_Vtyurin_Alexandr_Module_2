Приведённая программа реализует телефонную книгу на основе линейного упорядоченного двухсвязного списка.
Выделение памяти для новых элементов происходит за счёт malloc.
    - Контакты в списке всегда отсортированы по лексикографическому порядку ФИО (Фамилия -> Имя -> Отчество). Вставка нового элемента происходит не в конец, а на строго определённую позицию с сохранением порядка при помощи функции list_insert_sorted(phone_book.c).
    - Каждый узел хранит указатели на предыдущий (prev) и следующий (next) элементы. Это позволяет обходить список в обоих направлениях и удалять узел из любой точки.
    - Если у контакта меняется фамилия или имя, программа аккуратно извлекает узел из текущей позиции, перелинковывает его соседей и заново вставляет узел на правильное место по алфавиту без перевыделения данных.

Используемые структуры

- FullName (ФИО контакта)
    typedef struct FullName {
        char lastName[MAX_NAME_LEN];   // Обязательное поле 
        char firstName[MAX_NAME_LEN];  // Обязательное поле 
        char secondName[MAX_NAME_LEN]; // Опциональное поле 
    } FullName;

- Address (Почтовый адрес)
    typedef struct Address {
        char postalCode[16];           // Почтовый индекс 
        char country[MAX_NAME_LEN];    // Страна 
        char region[MAX_NAME_LEN];     // Регион / область 
        char city[MAX_NAME_LEN];       // Населенный пункт 
        char street[MAX_STR_LEN];      // Улица 
        char house[16];                // Номер дома 
        char apartment[16];            // Номер квартиры/офиса 
    } Address;

- Contact (Узел двухсвязного списка)
    typedef struct Contact {
        int id;                                 // Неизменяемый идентификатор 
        FullName name;                          // Вложенная структура ФИО 
        char phones[MAX_PHONES][MAX_PHONE_LEN]; // Массив телефонов 
        size_t phoneCount;                      // Текущее число телефонов 
        Address addresses[MAX_ADDRESSES];       // Массив адресов 
        size_t addressCount;                    // Текущее число адресов 

        struct Contact *prev;                   // Указатель на предыдущий контакт 
        struct Contact *next;                   // Указатель на следующий контакт 
    } Contact;


Методы обработки данных в списке 

- int contact_add(Contact **head, size_t *count, int *next_id, const FullName *person, const char *format, ...)
    Принимает: указатель на указатель головы списка head, указатель на счётчик count, генератор уникальных ID next_id, структуру ФИО person, строку формата format и список вариативных аргументов (%s — отчество, %p — телефон, %a — адрес).
    Функция выделяет память под новый узел, присваивает уникальный ID, парсит дополнительные поля через va_list и вставляет узел в список в алфавитном порядке. Если фамилия меньше головы, узел становится новой головой.
    Возвращает: присвоенный ID контакта (> 0) при успехе или -1 при ошибке выделения памяти.

- const Contact* contact_find_by_id(const Contact *head, int id)
    Принимает: указатель на голову списка head и искомый числовой id.
    Функция последовательно проходит по цепочке next, сравнивая идентификаторы.
    Возвращает: константный указатель на найденный узел Contact или NULL, если контакт с указанным ID отсутствует.

- int contact_delete(Contact **head, size_t *count, int id)
    Принимает: указатель на голову head, указатель на счётчик count, идентификатор удаляемого контакта id.
    Функция находит узел в списке, перенаправляет связи его соседей в обход удаляемого узла (если удаляется голова — смещает *head на следующий элемент), освобождает память через free() и уменьшает счётчик *count.
    Возвращает: 0 при успешном удалении, -1 если контакт с таким ID не найден.

- int contact_update_name(Contact **head, int id, const char *format, ...)
    Принимает: указатель на голову head, идентификатор id, строку формата (%l — фамилия, %f — имя, %s — отчество) и структуру с новыми строками FullName.
    Функция находит контакт, обновляет указанные компоненты имени. Если алфавитный порядок нарушился, функция временно отсоединяет узел из списка и повторно вставляет его на правильную позицию.
    Возвращает: 0 при успехе, -1 если контакт не найден.

- int contact_add_phone(Contact *head, int id, const char *phone)
    Принимает: голову списка head, ID контакта и строку с номером телефона.
    Функция находит контакт и добавляет номер в массив phones, если не достигнут лимит MAX_PHONES (5 номеров).
    Возвращает: 0 при успехе, -1 при переполнении лимита или если контакт не найден.

- int contact_remove_phone(Contact *head, int id, size_t phone_idx)
    Принимает: голову списка head, ID контакта и порядковый индекс удаляемого номера (0-based).
    Функция удаляет номер телефона со сдвигом оставшихся строк влево и декрементом счётчика phoneCount.
    Возвращает: 0 при успехе, -1 при некорректном индексе.

- int contact_add_address(Contact *head, int id, const Address *addr)
    Принимает: голову списка head, ID контакта и указатель на структуру Address.
    Функция копирует структуру адреса в массив addresses, если не достигнут лимит MAX_ADDRESSES (3 адреса).
    Возвращает: 0 при успехе, -1 при переполнении или отсутствии контакта.

- int contact_remove_address(Contact *head, int id, size_t addr_idx)
    Принимает: голову списка head, ID контакта и индекс адреса.
    Функция удаляет структуру адреса со сдвигом последующих элементов влево и уменьшением addressCount.
    Возвращает: 0 при успехе, -1 при ошибке.

- void contact_free_all(Contact **head, size_t *count)
    Принимает: указатель на указатель головы head и указатель на счётчик count.
    Функция проходит по всему списку слева направо, освобождая каждый узел через free(). После завершения зануляет *head = NULL и сбрасывает счётчик *count = 0.
    Возвращает: ничего.

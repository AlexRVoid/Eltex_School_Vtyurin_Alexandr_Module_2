Приведённая программа реализует циклическую очередь с приоритетом на основе  пула узлов ёмкости (16 слотов) с двухиндексной организацией связей.
Выделение динамической памяти отсутствует: вся память под задачи зарезервирована в массиве pool[QUEUE_CAPACITY].
    - Приоритеты разбиты на 8 классов в диапазоне от 0 (наивысший) до 255 (наихудший). Каждый класс объединяет 32 значения приоритета (level = prio / 32).
    - Очередь работает в циклическом режиме: при заполнении всех 16 слотов новая задача всегда гарантированно сохраняется в буфере, вытесняя самую старую задачу среди имеющих наихудший приоритет.
    - Каждый узел одновременно состоит в двух линейных двусвязных списках: отсортированном по приоритету (head_prio ... tail_prio) и хронологическом по времени поступления (head_time .. tail_time).
    - Реализованы три варианта выборки: первой задачи (наивысший приоритет, при равенстве — FIFO), задачи с точным приоритетом и задачи с приоритетом не ниже заданного порога.

Используемые структуры:

- Task (Данные задачи)
    typedef struct Task{
        int id;                 // Уникальный ID задачи 
        uint8_t prio;           // Точный приоритет (0 - высший, 255 - низший) 
        uint8_t level;          // Уровень приоритета 0..7 (prio / 32) 
        uint32_t seq;           // Счетчик порядка добавления для строгого FIFO 
    } Task;

- TaskNode (Узел очереди)
    typedef struct TaskNode {
        Task task;
        struct TaskNode *prev_prio, *next_prio; // Список по приоритету (0 -> 255) 
        struct TaskNode *prev_time, *next_time; // Список по времени прибытия (FIFO) 
    } TaskNode;

- PriorityQueue (Дескриптор очереди)
    typedef struct PriorityQueue{
        TaskNode pool[QUEUE_CAPACITY];
        TaskNode *free_list;

        TaskNode *head_prio;    // Наивысший приоритет (ближе к 0) 
        TaskNode *tail_prio;    // Наихудший приоритет (ближе к 255) 

        TaskNode *head_time;    // Самая старая задача в очереди 
        TaskNode *tail_time;    // Самая свежая задача в очереди 

        size_t size;
        uint32_t next_seq;
        int next_id;
    } PriorityQueue;

- PushResult (Результат добавления)
    typedef enum PushResult{
        PUSH_SUCCESS = 0,       // Добавлено в свободный слот 
        PUSH_OVERFLOW_EVICTED   // Очередь была полна: вытеснена самая старая задача с худшим приоритетом 
    } PushResult;


Методы обработки данных в списке 

- void pqueue_init(PriorityQueue *pq)
    Принимает: указатель на дескриптор очереди pq.
    Функция обнуляет дескриптор, объединяет ячейки статического массива в цепочку свободных блоков free_list и сбрасывает счётчики ID и времени.
    Возвращает: ничего.

- PushResult pqueue_push(PriorityQueue *pq, uint8_t prio, Task *out_evicted)
    Принимает: указатель на очередь pq, числовой приоритет prio (0..255) и указатель out_evicted для сохранения копии вытесненной задачи.
    Функция гарантированно сохраняет новую задачу в буфере. Если все 16 слотов заняты, находит самую старую задачу среди имеющих наихудший приоритет, копирует её в out_evicted, исключает из очереди и переиспользует её слот. Новый узел подшивается в хвост списка времени и на отсортированную позицию в списке приоритетов.
    Возвращает: PUSH_SUCCESS при наличии свободного места или PUSH_OVERFLOW_EVICTED при циклическом вытеснении.

- int pqueue_pop_first(PriorityQueue *pq, Task *out_task)
    Принимает: указатель на очередь pq и указатель out_task для сохранения извлечённых данных.
    Функция извлекает узел из головы списка приоритетов (head_prio). Это задача с наивысшим приоритетом (минимальный prio), а при наличии дубликатов — наиболее ранняя по времени поступления. Освободившийся слот возвращается в free_list.
    Возвращает: 1 при успешном извлечении или 0, если очередь пуста.
- int pqueue_pop_exact(PriorityQueue *pq, uint8_t prio, Task *out_task)
    Принимает: указатель на очередь pq, целевой приоритет prio и указатель out_task.
    Функция: ищет в списке приоритетов задачу со значением task.prio == prio. При обнаружении извлекает её. Если задача с точным приоритетом отсутствует, автоматически вызывает метод pqueue_pop_closest_not_lower для извлечения ближайшей подходящей задачи.
    Возвращает: 1 при успешной выборке (точного значения или через фоллбэк) или 0, если подходящих задач в диапазоне нет.
- int pqueue_pop_closest_not_lower(PriorityQueue *pq, uint8_t target_prio, Task *out_task)
    Принимает: указатель на очередь pq, пороговый приоритет target_prio и указатель out_task.
    Функция ищет задачу с приоритетом не ниже заданного (то есть численный приоритет <= target_prio), максимально близким к переданному значению порога. Найденный узел исключается из обоих списков и возвращается в пул.
    Возвращает: 1 при успешном нахождении и извлечении или 0, если в очереди нет задач с приоритетом <= target_prio.
- void pqueue_clear(PriorityQueue *pq)
    Принимает: указатель на очередь pq.
    Функция сбрасывает указатели головы и хвоста обоих списков и заново пересобирает стек свободных узлов free_list.
    Возвращает: ничего.
- const char* pqueue_get_level_name(uint8_t level)
    Принимает: номер класса обслуживания level (0..7).
    Функция сопоставляет номер уровня с его текстовым названием по классификации QoS сетевого оборудования.
    Возвращает: строковое имя класса обслуживания.

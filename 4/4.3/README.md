Приведённая программа реализует телефонную книгу на основе бинарного дерева поиска (BST) с периодической балансировкой каждые 3 модификации дерева.
Выделение памяти для каждого контакта происходит динамически в куче за счёт malloc.
    - Узлы дерева упорядочены по лексикографическому порядку ФИО (Фамилия -> Имя -> Отчество). Для полных тёзок в качестве тайбрейкера используется сравнение уникальных идентификаторов id. Для любого узла значения в левом поддереве строго меньше ключа узла, а в правом — строго больше.
    - Каждый узел хранит вычисленную высоту своего поддерева height, что позволяет вычислять фактор баланса узла: bf = h_left - h_right.
    - Балансировка дерева выполняется через симметричный обход In-Order (LTR) в массив указателей с последующей рекурсивной сборкой сбалансированного дерева делением массива пополам.
    - Поддерживаются три канонических порядка обхода дерева: симметричный (LTR, алфавитный), прямой (TLR, структурный) и обратный (LRT, постфиксный).
    - Очистка всей памяти телефонной книги реализована строго через постфиксный обход Post-Order (LRT): память родительского узла освобождается только после полной очистки обоих его потомков, что исключает ошибки обращения к уже освобождённой памяти.

Используемые структуры:

- FullName (ФИО контакта)
    typedef struct FullName {
        char lastName[MAX_NAME_LEN];   // Обязательное поле
        char firstName[MAX_NAME_LEN];  // Обязательное поле
        char secondName[MAX_NAME_LEN]; // Опциональное поле
    } FullName;

- Address (Почтовый адрес)
    typedef struct Address {
        char postalCode[16];           // Почтовый индекс
        char country[MAX_NAME_LEN];    // Страна
        char region[MAX_NAME_LEN];     // Регион / область
        char city[MAX_NAME_LEN];       // Населенный пункт
        char street[MAX_STR_LEN];      // Улица
        char house[16];                // Номер дома
        char apartment[16];            // Номер квартиры/офиса
    } Address;

- Contact (Узел бинарного дерева поиска)
    typedef struct Contact {
        int id;                                 // Неизменяемый идентификатор
        FullName name;                          // Вложенная структура ФИО
        char phones[MAX_PHONES][MAX_PHONE_LEN]; // Массив телефонов
        size_t phoneCount;                      // Текущее число телефонов
        Address addresses[MAX_ADDRESSES];       // Массив адресов
        size_t addressCount;                    // Текущее число адресов

        int height;                             // Высота поддерева для расчета bf 
        struct Contact *left;                   // Левый потомок 
        struct Contact *right;                  // Правый потомок 
    } Contact;

- TreeOrder (Порядки канонических обходов)
    typedef enum {
        ORDER_LTR, // Симметричный: Левый -> Корень -> Правый (по алфавиту)
        ORDER_TLR, // Прямой:       Корень -> Левый -> Правый (структурный)
        ORDER_LRT  // Обратный:     Левый -> Правый -> Корень (постфиксный)
    } TreeOrder;

Методы обработки данных в дереве:

- int contact_add(Contact root, size_t *count, int *next_id, const FullName *person, const char *format, ...)
    Принимает: указатель на указатель корня root, указатель на счётчик count, генератор уникальных ID next_id, структуру ФИО person, строку формата format и список вариативных аргументов (%s — отчество, %p — телефон, %a — адрес).
    Функция выделяет память под новый узел, присваивает уникальный ID, парсит вариативные поля через va_list и спускается по дереву согласно правилам BST, размещая новый лист и пересчитывая высоты родительских узлов.
    Возвращает: присвоенный ID контакта (> 0) при успехе или -1 при ошибке выделения памяти.

- const Contact* contact_find_by_id(const Contact *root, int id)
    Принимает: указатель на корень дерева root и искомый числовой id.
    Функция выполняет рекурсивный поиск в глубину (DFS) по всему дереву, сравнивая поле идентификатора.
    Возвращает: константный указатель на найденный узел Contact или NULL, если контакт с данным ID отсутствует.

- int contact_delete(Contact root, size_t *count, int id)
    Принимает: указатель на указатель корня root, указатель на счётчик count, идентификатор удаляемого контакта id.
    Функция находит контакт по ID и выполняет удаление узла с пересчётом высот. Корректно обрабатывает удаление листа, узла с одним потомком и узла с двумя потомками (с поиском in-order successor — минимального узла в правом поддереве). Освобождает память удалённого узла через free() и уменьшает счётчик count.
    Возвращает: 0 при успешном удалении или -1, если контакт с данным ID не найден.

- int contact_update_name(Contact root, int id, const char *format, ...)
    Принимает: указатель на указатель корня root, идентификатор контакта id, строку формата (%l — фамилия, %f — имя, %s — отчество) и структуру FullName с новыми данными.
    Функция находит контакт в дереве, копирует его номера и адреса, удаляет старый узел из дерева и заново вставляет его на правильную лексикографическую позицию в дереве.
    Возвращает: 0 при успехе или -1, если контакт не найден.

- int contact_add_phone(Contact *root, int id, const char *phone)
    Принимает: корень дерева root, ID контакта и строку с номером телефона.
    Функция находит контакт по ID через DFS и добавляет номер в массив phones, если не превышен лимит MAX_PHONES (5 номеров).
    Возвращает: 0 при успехе или -1 при переполнении лимита либо отсутствии контакта.

- int contact_remove_phone(Contact *root, int id, size_t phone_idx)
    Принимает: корень дерева root, ID контакта и порядковый индекс удаляемого номера (0-based).
    Функция находит контакт, удаляет номер со сдвигом последующих записей влево и декрементирует счётчик phoneCount.
    Возвращает: 0 при успехе или -1 при некорректном индексе.

- int contact_add_address(Contact *root, int id, const Address *addr)
    Принимает: корень дерева root, ID контакта и указатель на структуру Address.
    Функция находит контакт по ID и копирует структуру адреса в массив addresses, если не превышен лимит MAX_ADDRESSES (3 адреса).
    Возвращает: 0 при успехе или -1 при переполнении массива либо отсутствии контакта.

- int contact_remove_address(Contact *root, int id, size_t addr_idx)
    Принимает: корень дерева root, ID контакта и порядковый индекс адреса.
    Функция находит контакт, удаляет структуру адреса со сдвигом последующих элементов влево и уменьшает addressCount.
    Возвращает: 0 при успехе или -1 при выходе индекса за границы.

- int contact_balance(Contact root, size_t count)
    Принимает: указатель на указатель корня root и общее количество узлов count.
    Функция обходит дерево в алфавитном порядке In-Order (LTR), сохраняя указатели на узлы во временный массив за $O(N)$, после чего рекурсивным делением массива пополам пересобирает сбалансированное бинарное дерево поиска с пересчётом высот.
    Возвращает: 0 при успехе или -1 при ошибке выделения памяти под временный массив.

- int contact_check_auto_balance(Contact root, size_t count, int *was_balanced)
    Принимает: указатель на указатель корня root, количество узлов count и указатель на флаг was_balanced.
    Функция инкрементирует внутренний счётчик модификаций дерева. При достижении значения AUTO_BALANCE_PERIOD (3) сбрасывает счётчик, выполняет глобальную балансировку через contact_balance и выставляет значение *was_balanced = 1.
    Возвращает: 0.

- void contact_traverse(const Contact *root, TreeOrder order, void (*callback)(const Contact *))
    Принимает: указатель на корень дерева root, тип обхода order (ORDER_LTR, ORDER_TLR, ORDER_LRT) и указатель на функцию обратного вызова callback.
    Функция рекурсивно обходит дерево в выбранном порядке и передаёт указатель на каждый посещённый контакт в callback.
    Возвращает: ничего.

- int contact_get_height(const Contact *root)
    Принимает: указатель на корень дерева или поддерева root.
    Функция возвращает сохранённую высоту поддерева. Для NULL возвращает 0.
    Возвращает: целочисленную высоту поддерева.

- int contact_get_bf(const Contact *root)
    Принимает: указатель на узел root.
    Функция вычисляет фактор баланса узла как разность высот его левого и правого поддеревьев ($h_{\text{left}} - h_{\text{right}}$).
    Возвращает: целое число (фактор баланса).

- void contact_load_presets(Contact root, size_t *count, int *next_id)
    Принимает: указатель на указатель корня root, указатель на счётчик count и генератор ID next_id.
    Функция добавляет 8 предустановленных контактов с фамилиями в строго алфавитном порядке (от Alekseev до Sidorov) и принудительно выставляет счётчик изменений в значение 8 для демонстрации периодической балансировки.
    Возвращает: ничего.

- void contact_print_tree(const Contact *root)
    Принимает: указатель на корень дерева root.
    Функция выводит иерархическую структуру дерева в консоль с графическими ветками (├─, └─, │), отображая высоту h и фактор баланса bf каждого узла.
    Возвращает: ничего.

- void contact_free_all(Contact root, size_t *count)
    Принимает: указатель на указатель корня root и указатель на счётчик контактов count.
    Функция рекурсивно обходит дерево в постфиксном порядке LRT, освобождая память каждого узла через free(), после чего зануляет *root = NULL, сбрасывает *count = 0 и обнуляет внутренний счётчик изменений.
    Возвращает: ничего.
